# Authored catalogue composite control

`composite.pdf` is wholly authored fictional test material, not a user document.
Its text is “Fictional café Ångström résumé”. The layout is a single500×700pt page,
12pt DejaVuSans at40pt margins. It was generated with installed PDFKit0.20.2 and
pinned fontkit2.0.4 from the existing licensed `public/fonts/DejaVuSans.ttf`.
Font licensing remains the existing DejaVu licence in `public/fonts/LICENSE`;
the newly authored words/layout are CC0. No personal profile or source was used.

This exercises positive compound glyphs and exact complete-byte reconstruction
of the embedded subset from licensed full catalogue bytes. It does not grant
permission metadata to the uploaded subset or qualify generic fonts. Normal
browser byte-parity testing is a separate root-owned acceptance gate.
